This is the React / Vite Single Page Application (SPA) for BillFlow-Pro.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server (uses Vite HMR):
   ```bash
   npm run dev
   ```

3. Lint code (uses Oxlint):
   ```bash
   npm run lint
   ```

4. Build for production (outputs to `dist/`):
   ```bash
   npm run build
   ```
